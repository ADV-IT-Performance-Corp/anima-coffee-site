# Security policy

This repository is the static site https://aeo.animacoffee.com.ua (GitHub Pages; merging to `main` deploys).

To report a vulnerability, email animacoffeeco@gmail.com (see `.well-known/security.txt`). Please do not open a public issue for security problems and do not include real customer data in reports.

Scope: the site, its scripts under `assets/`, the lead form and chat widget, and the WebMCP tools. Secrets, API keys and server-side tokens must never be committed to this repository.
