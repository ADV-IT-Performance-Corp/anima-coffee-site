# Security policy

This repository is the live static site https://aeo.animacoffee.com.ua (GitHub Pages; a merge to `main` deploys).

To report a vulnerability, email animacoffeeco@gmail.com (also published in `/.well-known/security.txt`). Please do not open a public issue for a vulnerability. Do not include personal data of third parties in a report.

Secrets must never be committed. Lead delivery goes through Roistat and the configured endpoint only.
