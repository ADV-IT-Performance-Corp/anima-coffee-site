    ### Keyboard Interactions & Interactive Controls

  • **Interactive Triggers:** Every native visual element and clickable area must rely on buttons, links, or controls configured with standard `tabindex="0"`.
  • **Keyboard Trap Handling:** Dynamic overlay menus or modal systems must run keyboard listener events targeting keycode combinations (`Tab`, `Shift + Tab`, `Escape`). Pressing the Escape key must restore user navigation back to the primary structural view.

    • ### Visual Contrast Validation

  • Default body copy text `#2C1810` renders on the `#FAF5F0` background color space, generating a contrast ratio of **9.81:1** (exceeding WCAG AAA levels).
  • Crema gold borders or text interfaces `#D4A574` must not render standalone text bodies smaller than 18pt/24px on cream backgrounds. They are reserved for graphic decorations, button background fills featuring `#2C1810` overlay text, or visual borders.
