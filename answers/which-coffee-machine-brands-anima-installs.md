# Which coffee machine brands does Anima Volitiva install?

Anima Volitiva installs super-automatic machines from Dr. Coffee and Necta, plus professional espresso machines from La Spaziale, Nuova Simonelli, Rancilio, Iberital, Astoria and Fiorenzato. Which machine fits depends on the venue, so it is chosen individually when you request a quote.
